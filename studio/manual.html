CHAPTER 01 · Home / Ghost Rack → links below the console

Choose the right workspace

The app has separate audio sessions and several kinds of saved files. Start by choosing the workspace for your task.

  1. Ghost Rack — One audio source through Dynamics A
  2. Full DAW — Multiple tracks, arrangement and mixing
  3. Plugin Prompt Forge — Text recipes from your supplied ZIP
  4. Radio — Stream and submit station songs
  5. Lyrics — Writing brief and temporary drafts
  6. Plugin workshop — Build actual DAW effect chains

How to use it

  1. Open the studio. The photographic console is Ghost Rack; /rack opens the same console directly.
  2. For one-file compression, stay in Ghost Rack. For stems, editing or multi-track mixing, use Full DAW below the rack.
  3. Use Radio to listen to or upload station tracks. A radio upload does not load a track into the rack or DAW.
  4. Use Lyrics for writing. Use Plugin workshop for actual DAW inserts; the prompt library supplies text instructions.
  5. Keep the manual in another tab. Use its search box to find the exact label on your screen.

CHAPTER 02 · Ghost Rack → Upload audio and transport

Play a song in the 3D rack

The rack runs one Dynamics A compressor on a mono or stereo audio file. Its other category buttons open plugin references.

  1. Upload audio — Choose the recording on your device
  2. Play / Pause — Start or pause the current source
  3. Previous / Next — Move backward or forward five seconds
  4. Timecode / seek bar — Read and change playback position
  5. Waveform / IN / OUT — See the current signal and levels
  6. Record — Capture microphone audio

How to use it

  1. Tap Upload audio and select your recording. Wait for the filename and duration to appear.
  2. Press Play. Move the seek bar to another part of the song; Pause holds the position.
  3. Use Previous or Next to jump five seconds. These are not previous-song and next-song controls.
  4. Watch the IN and OUT meters while listening. The waveform is the output signal, not a measurement of mastering quality.
  5. To record instead, tap Record and allow the microphone. Tap Record again to finish; the take becomes the rack source. Save your existing project before replacing its source.
Control / itemWhat it does
Play with no fileLoads the synthesized sound check. This is demo audio, not your song.
Microphone monitoringListening is muted while recording to reduce feedback; the take is captured dry.
Track limitsRack import supports mono and stereo. Browser codec and memory limits still apply.
Separate sessionThe rack does not insert itself into a Full DAW track. Export a WAV if you want to transfer its processed result.

CHAPTER 03 · Ghost Rack → six dials and action buttons

Adjust Dynamics A

Drag a dial upward to increase it and downward to decrease it. Start with Ghost Neutral Start when you want no compression or added gain.

  1. Threshold — Level where compression begins
  2. Ratio — Compression strength above threshold
  3. Attack — Response time in milliseconds
  4. Release — Recovery time in milliseconds
  5. Knee — Width of the soft transition
  6. Makeup — Gain after compression

How to use it

  1. Open Presets and load Ghost Neutral Start if you have imported it. Its ratio is 1:1 and makeup is 0 dB.
  2. Play a representative loud section. Enable IN and keep BYPASS off when auditioning processing.
  3. Drag one dial at a time. On a keyboard, use arrow keys; Shift gives finer adjustment during dragging.
  4. Compare BYPASS and IN at similar listening levels. Read GAIN REDUCTION to see how much the compressor is acting.
  5. Use A/B to switch between two settings snapshots. Save or download a preset when you want to keep a setting.
Control / itemWhat it does
Threshold−60 to 0 dB. A threshold by itself does not determine gain reduction; source level and ratio matter.
Ratio1:1 to 20:1. At 1:1, no compression is applied.
Attack / ReleaseAttack: 0–1,000 ms. Release: 1–1,000 ms. Timing values must be valid, not all literal zero.
Knee / MakeupKnee: 0–40 dB. Makeup: −12 to +24 dB.
IN / BYPASSIN off or BYPASS on passes the dry source. Neither unloads your song.
SOLOThere is only one source in this rack. SOLO is a state indicator and does not isolate a separate stem or detector signal.
RESET / double-clickRestores the rack’s original default settings, not Ghost Neutral Start: −18 dB, 4:1, 10 ms, 120 ms, 6 dB knee, +3 dB makeup.
A/BChanges settings snapshots, not source recordings. The current slot is shown on the button.

CHAPTER 04 · Ghost Rack → Presets

Import and save presets

A preset contains Dynamics A settings only. Importing it updates the six dials without replacing the loaded song.

  1. Import preset — Pick a compatible JSON file
  2. Load preset — Apply a saved or factory setting
  3. Preset name — Name your current settings
  4. Save preset — Keep it in this browser
  5. Download current settings — Create a portable preset file
  6. Export saved bank — Download all user presets

How to use it

  1. Download Ghost-Dynamics-A-Neutral.json to your device if you want the neutral starter.
  2. Open Presets → Import preset. Choose the JSON from Downloads. Read the result message; it names the preset loaded.
  3. Select Ghost Neutral Start in Load preset. Check ratio 1:1 and makeup 0 dB on the rack.
  4. To keep your own changes, adjust the dials, open Presets, enter a name, then tap Save preset.
  5. Tap Download current settings for a portable file, or Export saved bank to back up all user presets.
  6. After a refresh, open Presets → Load preset. If the name is still listed, this browser retained it. Export before clearing browser data.

CHAPTER 05 · Ghost Rack → Projects

Save and export a rack project

A rack project preserves its source audio, current settings, A/B snapshots, playback position and switch states. A WAV contains rendered sound only.

  1. Save project — Download the rack project JSON
  2. Open project — Restore audio and rack state
  3. Export WAV — Render the current rack result
  4. Monitor volume — Listening level only
  5. Clipping message — Lower makeup before export
  6. Settings — Visuals, meters and sound check

How to use it

  1. Open Projects → Save project before replacing a recording or leaving the rack. Keep the downloaded JSON.
  2. To restore it, use Projects → Open project and choose that rack project. This can replace the current source and pauses playback.
  3. To create an audio file, load your source, set IN/BYPASS and compressor controls, then choose Export WAV.
  4. If export reports an output above 0 dBFS, lower Makeup and export again. The rack refuses a clipped integer WAV.
  5. Open the downloaded WAV and listen. Keep the project separately if you need editable settings.
Control / itemWhat it does
WAV formatRack export is 16-bit PCM at the source buffer’s sample rate, with one or two channels.
Monitor volumeAffects listening but is not included in the exported WAV.
Project limitRack project import is limited to 180 MB. Use its own project loader, not the Full DAW project loader.
Settings switchesAnimated waveform, LED meters and Reduced motion change visuals. Load sound check replaces the source with the procedural demo.

CHAPTER 11 · DAW → Mixer, below Arrangement

Faders, knobs and the master bus

Each imported stem gets a channel strip. The master controls the combined output. Start by balancing tracks before adding processing.

  1. Track name — Select this channel
  2. Pan knob — Place sound left or right
  3. Vertical fader — Set track level
  4. M · S — Mute / Solo
  5. MASTER output trim — Level of the combined mix
  6. Master rack / Master inserts — Effects on the combined mix

How to use it

  1. Select the stem you want to balance.
  2. Play the mix and drag its fader; center its pan knob if you do not want panning.
  3. Use M to mute or S to solo; clear unwanted solos before exporting.
  4. Open Master inserts only when you intend to affect the entire mix.
Control / itemWhat it does

Pan knobCenter is 0; left is −1 and right is +1. Drag vertically or use arrow keys. Double-click resets.

A workshop plugin is a chain of browser audio processors. It is not a VST or AU plugin file. The selected destination matters: a track chain affects one stem; the master chain affects the whole mix.

  2. Plugin name / Add module — Name it and choose processors
  3. Module controls — Enable, adjust and compare
  4. Destination / Insert chain — Selected stem or master bus
  5. Save / Download / Import plugin — Reuse your custom chain

How to use it

  2. Open Plugin workshop. Tap New chain, give it a name, select a module, then Add module.
  3. New modules start neutral and bypassed. Enable the module and adjust only what you need. A wet/dry Mix of 0% still gives dry sound.

CHAPTER 15 · Selected track → Analyze; Plugin workshop → Repair → Stem Cleanup

Analyze stems and remove noise

Work from the cleanest source you have. Cleanup can reduce some noise and isolated clicks, but it cannot guarantee reconstruction of damaged or clipped audio.

  1. Track role — Choose vocal, drums, bass or instrument
  2. Analyze stem — Measure the source before effects
  3. Source measurements — Peak, RMS, crest, DC and channels
  4. Insert suggestion / Apply needed plugins — Apply a measured starting point
  5. Stem Cleanup — Noise reduction and click repair
  6. Undo / bypass / compare — Check whether the change helps

How to use it

  1. Import the original stems and set their roles in Track detail.
  2. Select one stem and Analyze it. Read the explanation beside each suggestion.
  3. Use Insert suggestion for one recommendation, or ask Ghost: Apply needed plugins to the selected stem.
  4. Audition the result. Compare with the original at similar volume. Reduce or undo settings if consonants, transients or sustained notes sound damaged.
  5. Stem Cleanup can require background preparation. Playback continues with the previous result until the updated sound is ready. Read the preparation status before judging the new settings.
Control / itemWhat it does
Apply needed pluginsThis supported local command measures audible imported stems and applies justified processing. Add ‘to the selected stem’ to limit it to one track.
Noise ReductionMaximum reduction strength in dB. Start from 0; increase only when necessary.
Noise FloorDetection reference in dBFS. The neutral 0 value is not an instruction to use it as a real measured noise floor.
Click RepairRepair strength for isolated clicks. Aggressive values can damage legitimate transients.
MixBlends processed and dry signal. At 0%, the original dry signal remains.
S / T harshnessSmart De-Esser Pro or Dynamic Master Control may help specific harshness; they cannot reliably remove every AI artifact.
