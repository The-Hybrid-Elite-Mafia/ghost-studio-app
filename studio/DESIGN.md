# Studio design

The user pinned a black, cyan, violet holographic workstation. One operable desk: timeline and physical mixer on the left, Ghost on the right, an in-place plugin workshop below. No marketing sections.

Use Space Grotesk for title and control headings, system sans for prose, tabular monospace only for audio readings. Black-blue panels carry restrained bevels and perspective; cyan marks audio activity and primary actions, violet identifies custom effects. Text stays pale enough to read in the dark environment.

The signature interaction is real pointer/keyboard knob rotation with parameter updates, accompanied by an articulated WebGL Ghost following the focused control. Dragging the avatar or using its orbit slider changes the actual 3D view. Reduced motion disables autonomous animation. The original image remains available in the artwork view.

Responsive layout stacks Ghost below the mixer on small screens; only the timeline intentionally scrolls sideways. Empty, processing, unavailable, error and saved states are explicit.

The vocal/mastering expansion uses restrained amber, cream, silver, blue-grey and gold hardware panels within the cyan/violet studio. Metal knobs remain keyboard operable. Six collapsible groups keep the fixed Master Rack Pro readable. Meter bars and VU needles use actual audio telemetry; frequency charts label static response explicitly. Factory cards expose zero insertion and opt-in sound presets. The master bus and selected-track editor have distinct destination labels.
